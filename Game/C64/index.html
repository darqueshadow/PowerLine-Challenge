Using the C64

How to use it

  1. Pick a disk from the crates on the left.
  2. Insert Disk puts it in the drive. A tape goes in the datasette. If a game is running, it ends first.
  3. Load loads the game and runs it. If it asks, choose Play or Instructions. If the button says Run, click it to start what was loaded.
  4. Load "$",8 + List shows what is on the disk.
  5. When the game asks for another disk or side, click Swap disk.
  6. Pause freezes the game. Click it again to carry on.
  7. Full Screen fills the window with the game. Exit Full Screen brings the disks back.
  8. Eject, End Game takes the disk out and ends the game, back to READY.
  9. Reset (F12) goes back to the boot screen. The disk stays in.
  10. Power turns the C64 off and takes you back to the Arcade.
  • Joystick not working? Press F9 to try the other port.
  • Arrows moving the cursor instead of the joystick? Press F2.
  • Keys not typing? Let go of fire (Ctrl) first.

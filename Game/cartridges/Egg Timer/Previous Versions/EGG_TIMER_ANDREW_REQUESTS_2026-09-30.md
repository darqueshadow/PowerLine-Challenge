# Andrew's three requests, 2026-09-30 (pasted into the Egg Timer session, filed verbatim)

## 1. Upright scurry

The aliens roll as they leave. Keep them upright for the whole
scurry: no tipping or spinning. They should run off sideways with
their legs or tentacles moving and a small bob, like they're
scuttling away.

## 2. Hose

Hose change: any part of the water stream that touches egg goo or
shell pieces should push them, not just the end of the spray. The
pieces get blown along in the direction the water is flowing. The
stronger or closer the water, the harder the push.

If the hose already works this way and I'm misreading it, tell me how
it works now before changing anything.

## 3. Exit

Add a way to exit Egg Timer and go back to the Arcade room, standing
at the Egg Timer table where you started.
- If the other cabinet games already have an exit key or button,
  use the same one so they all match. If there's no convention yet,
  propose one before building.
- Show it on screen the same way as the other inline key hints, e.g.
  "[Esc] Exit".
- Exiting mid-game should ask "Quit this game?" first, so a stray
  key press doesn't throw away a run.
